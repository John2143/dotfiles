The topic is `$ARGUMENTS`. If it is empty, think about whatever the conversation is currently working on.

Think, don't gather. Work from what is already in context: earlier investigation findings, the conversation, memories. Look something up only when a specific gap blocks the idea, use the smallest read or search that closes it, and say what you looked up.

Stay read-only: no edits, no commands that change state.

Write the result as free-form prose in chat: the idea, how you got there, and where you're unsure. Keep what the context shows separate from what you're inferring.

Then stop. Don't plan steps or start work. The user picks the next move (`/skill:investigation`, more pontificating, or `/skill:action`).
